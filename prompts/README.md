# Como usar os prompts

Não copie todos de uma vez em chats diferentes.
Leia `docs/DEVELOPMENT_PLAYBOOK.md` e respeite as dependências.

1. `00_ORCHESTRATOR.md`
2. `01_FOUNDATION.md`
3. em paralelo: `02_SHOPEE_AFFILIATE.md` + `04_WHATSAPP.md`
4. depois: `03_INTELLIGENCE_SCORE.md` + `06_ATTRIBUTION.md`
5. depois: `05_DISTRIBUTION.md` + `07_ACQUISITION_ROUTER.md`
6. `08_FRONTEND_ZERO.md`
7. `09_PLATFORM_ADMIN.md` pode evoluir gradualmente após Foundation
8. `10_META_ADS.md`
9. `11_LEARNING.md` somente com dados suficientes
10. `12_RELEASE_GATE.md`
