# Frontend — superfícies

## Linguagem

Inspirar-se nos princípios do Frontend Zero:
- leitura rápida;
- hierarquia forte;
- pouca poluição;
- status operacionais claros;
- ações relevantes próximas do contexto;
- dados reais por padrão;
- demo/visual mode separado quando necessário.
