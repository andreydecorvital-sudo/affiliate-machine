# MVP Acceptance Criteria

O MVP interno só pode ser considerado funcional quando existir evidência para todos os itens:

- [ ] banco aplica do zero;
- [ ] pg-boss processa retry sem duplicidade;
- [ ] Shopee Affiliate autentica;
- [ ] productOfferV2 retorna e normaliza ofertas;
- [ ] snapshots históricos persistem alterações;
- [ ] score v1 explica por que uma oferta foi aprovada;
- [ ] link afiliado contém tracking apropriado quando suportado;
- [ ] WhatsApp suporta pelo menos duas sessões de teste independentes;
- [ ] grupos são sincronizados e classificados por nicho;
- [ ] post lógico gera deliveries independentes;
- [ ] delivery falho pode ser retentado sem repetir deliveries concluídos;
- [ ] shortlink registra click e redireciona;
- [ ] conversion report sincroniza idempotentemente;
- [ ] commission ledger reconcilia estado/valor;
- [ ] landing captura UTM;
- [ ] group router seleciona grupo com capacidade;
- [ ] dashboard mostra post → click → conversion → commission;
- [ ] Platform Admin mostra DB/jobs/providers/sessions/health;
- [ ] kill switches funcionam;
- [ ] autopilot real permanece OFF por padrão;
- [ ] Release Gate certifica SHA congelado.
